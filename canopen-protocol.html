CANopen Protocol Reference Specification

Complete technical communication profile, PDO message mappings, CiA 301 / 408 object dictionary definitions, and bus telegram layouts for the CVP5-C proportional valve driver.

Standard
CiA 301 / CiA 408
Default Node-ID
10 (0x0A)
Default Bitrate
250 kbit/s
CAN Identifiers
11-bit standard

1. Interface Overview

The CVP5-C integrates a certified CANopen slave communication stack based on Zephyr RTOS. It complies with CiA 301 (Application Layer and Communication Profile) and implements proportional hydraulic valve device profile definitions (CiA 408).

Key bus characteristics:

  • Frame Format: 11-bit standard CAN identifiers (CAN 2.0A).
  • Default Bitrate: 250 kbit/s (configurable via SDO or LSS to 125, 250, 500, or 1000 kbit/s).
  • Default Node-ID: 10 (decimal), 0x0A (hexadecimal). Range: 1 to 127.
  • NMT State Machine: Boot-up, Pre-Operational, Operational, and Stopped states supported.
  • Heartbeat Producer: Transmitted on 0x700 + Node-ID (0x70A default) every 1000 ms.

NMT Master Command Reference

Command Name Byte 0 Byte 1 State Transition / Effect
Start Remote Node 0x01 Target Node-ID or 0x00 (all) Enables Operational state. PDO transmission and reception activated.
Stop Remote Node 0x02 Target Node-ID or 0x00 (all) Enters Stopped state. Valve output de-energized.
Enter Pre-Operational 0x80 Target Node-ID or 0x00 (all) Stops PDOs; SDO communication remains active for commissioning.
Reset Node 0x81 Target Node-ID or 0x00 (all) Triggers hardware MCU reboot and re-initialization.
Reset Communication 0x82 Target Node-ID or 0x00 (all) Re-initializes CAN transceiver and CANopen protocol stack.

Heartbeat State Values

Payload Byte 0 NMT State Operational Status
0x00 Boot-up Transmitted once upon microcontroller power-up or reboot.
0x04 Stopped Device halted; valve current output is 0 mA.
0x05 Operational Normal operating state; RPDO1 commands active and TPDO telemetry running.
0x7F Pre-Operational Configuration state; SDO active, PDO processing suspended.

2. Process Data Objects (PDO) Interface

In Operational state, real-time control and telemetry are handled by cyclic PDOs. The CVP5-C delivers 1 Receive PDO (command setpoint) and 2 Transmit PDOs (feedback and diagnostics).

RPDO1 - EV1 Current Command Setpoint

Property Configured Value
Default COB-ID 0x200 + Node-ID (0x20A for default Node 10)
Data Length (DLC) 4 bytes (Bytes 0..1: active command; Bytes 2..3: padding 00 00)
Transmission Type 254 (Event-driven / asynchronous cyclic)
Mapped Object 0x6411:01 (CH1_Ref)
Byte Offset Field Name Data Type Endianness Description / Scaling
0 .. 1 CH1_Ref Unsigned 16-bit Little-endian Raw reference value scaled between 0 and (2resolution_bits - 1).
2 .. 3 Reserved Unsigned 16-bit Little-endian Unused in single-valve model; send 00 00.

TPDO1 - Real-Time Analog Telemetry

Property Configured Value
Default COB-ID 0x180 + Node-ID (0x18A for default Node 10)
Data Length (DLC) 8 bytes
Transmission Period 100 ms (event-driven / cyclic)
Mapped Objects 0x6401:01 (Iread_EV1), 0x6401:03 (Vread_EXT), 0x6401:04 (Vread_SPP)
Byte Offset Field Name Data Type Endianness Description / Engineering Unit
0 .. 1 Iread_EV1 Signed 16-bit Big-endian Measured solenoid coil current in milliamps (mA).
2 .. 3 Unused EV2 field Signed 16-bit Big-endian Inactive in single-valve configuration (reads 00 00).
4 .. 5 Vread_EXT Signed 16-bit Big-endian External analog input in mV. Value -123 (0xFF85) indicates unconnected.
6 .. 7 Vread_SPP Signed 16-bit Big-endian Controller power supply voltage in millivolts (mV) (e.g. 24000 = 24.0 V).

TPDO2 - Fault Status Telemetry

Property Configured Value
Default COB-ID 0x280 + Node-ID (0x28A for default Node 10)
Data Length (DLC) 3 bytes (Byte 0: EV1 fault byte; Bytes 1..2: unused padding 00 00)
Transmission Period 100 ms
Mapped Object 0x6421:01 (ErrorEV1)
Bit Offset Fault Name Fault Condition & Safe State
Bit 0 Maximum Current Exceeded Measured current exceeded the configured threshold in object 0x2102:01.
Bit 1 Open Circuit Detected Coil circuit is interrupted or disconnected.
Bit 2 Current Control Error Current regulation loop out of bounds or solenoid short-circuit detected (5 ms fast cutoff).
Bit 3 CAN Bus Error CAN communication warning or frame errors detected.
Bit 4 Supply Voltage Error Supply voltage outside 12 - 30 Vdc operating range.

3. SDO Object Dictionary

The CVP5-C integrates a standard expedited SDO server accessible on 0x600 + Node-ID (requests) and 0x580 + Node-ID (responses). All multi-byte SDO index/sub-index values and numerical data are transferred in little-endian format.

Communication & Device Profile Objects (0x1000 - 0x1018)

Index Sub Name Type Access Description / Default
0x1000 0 Device Type UNSIGNED32 ro CiA 408 profile specification.
0x1001 0 Error Register UNSIGNED8 ro Generic error register bitmask.
0x1010 1 Store Parameters UNSIGNED32 rw Write ASCII "save" (0x65766173) to persist parameters to non-volatile flash.
0x1011 1 Restore Default Parameters UNSIGNED32 rw Write ASCII "load" (0x64616F6C) to restore factory defaults.
0x1017 0 Producer Heartbeat Time UNSIGNED16 rw Heartbeat period in milliseconds. Default: 1000 ms.
0x1018 1 Vendor ID UNSIGNED32 ro Galileo Engineering vendor identifier.
0x1018 2 Product Code UNSIGNED32 ro CVP5-C product hardware code.
0x1018 3 Revision Number UNSIGNED32 ro Firmware major/minor revision.
0x1018 4 Serial Number UNSIGNED32 ro Unique 32-bit hardware production serial number.

Manufacturer-Specific Configuration Objects (0x2000 - 0x2110)

Index Sub Name Type Access Range & Function
0x2000 0 CANopen Node-ID UNSIGNED8 rw Configures the CANopen Node-ID (1 to 127). Default: 10.
0x2102 1 EV1 Max Current UNSIGNED16 rw Maximum solenoid current in mA (1 to 3000 mA). Default: 1000 mA.
0x2102 2 EV1 Offset Current UNSIGNED16 rw Pedestal offset current in mA (0 to 2000 mA). Default: 200 mA.
0x2102 3 EV1 Ramp Up UNSIGNED16 rw Acceleration ramp in mA/s (10 to 50000 mA/s). Default: 500 mA/s.
0x2102 4 EV1 Ramp Down UNSIGNED16 rw Deceleration ramp in mA/s (10 to 50000 mA/s). Default: 500 mA/s.
0x2102 5 EV1 Dither Amplitude UNSIGNED16 rw Dither amplitude percentage (0 to 20%). Default: 10%.
0x2102 6 ConvADC Coefficient UNSIGNED16 rw Current sensing calibration multiplier.
0x2102 8 Control Mode UNSIGNED16 rw Regulation operating mode. Default: 1.
0x2102 10 Command Resolution UNSIGNED16 rw Resolution bits for RPDO1 command (8 to 16 bits). Default: 8.
0x2105 5 Dither Frequency UNSIGNED16 rw Configurable dither frequency in Hz (50 to 300 Hz). Default: 125 Hz.
0x2108 1..101 EV1 Linearization Curve INTEGER16 ro 101-point calibration curve mapping PWM 0..100% to output current.

4. System Diagnostics & RGB LED Indicator

The CVP5-C integrates two layers of diagnostics: a physical RGB three-color status LED visible on the enclosure, and continuous CAN bus error telemetry.

LED State Operational Condition Diagnostic Action
Green Steady Normal Operational Mode Controller healthy, CAN communication established, current regulation active.
Green Blinking Pre-Operational Mode Node waiting for NMT Start command from CANopen master.
Red Steady Critical Hardware Fault Solenoid short-circuit detected (5 ms cutoff) or overvoltage on supply rails.
Red Blinking Open Circuit Fault Valve coil wiring interrupted or solenoid unplugged.
Blue / Yellow CAN Bus Error / Warning CAN bus frame errors, incorrect bitrate, or missing termination resistors.

5. Telegram Examples

Start Node into Operational State (NMT)

CAN-ID: 0x000   DLC: 2   DATA: 01 0A

Where 01 = Start command, 0A = Target Node-ID 10.

Command EV1 to 500 mA (RPDO1)

CAN-ID: 0x20A   DLC: 4   DATA: F4 01 00 00

0x01F4 represents 500 mA in unsigned 16-bit little-endian format.

Read EV1 Maximum Current via SDO (0x2102:01)

TX: CAN-ID: 0x60A   DLC: 8   DATA: 40 02 21 01 00 00 00 00
RX: CAN-ID: 0x58A   DLC: 8   DATA: 4B 02 21 01 B0 04 00 00   ; 0x04B0 = 1200 mA

Save All Parameters to Non-Volatile Flash (SDO)

TX: CAN-ID: 0x60A   DLC: 8   DATA: 23 10 10 01 73 61 76 65
RX: CAN-ID: 0x58A   DLC: 8   DATA: 60 10 10 01 00 00 00 00
